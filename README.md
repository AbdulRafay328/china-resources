# China Resources & Infrastructure Company (CRI) website

Holding site for CRI: a single "under construction" page. Built with Next.js and Tailwind CSS.

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Contact email

The "Contact" buttons open a new Gmail message to the company in a new tab and copy the company email to the visitor's clipboard. The address is set in `CONTACT_EMAIL` in `components/contact-button.tsx`.
